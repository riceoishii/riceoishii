# 中小企業向けAIエージェント導入：事業プラン（業種を絞らない版）

作成日：2026-11-11
根拠：`research/china-ai-expo-2026/` の調査。市場の数字は二次情報で一次確認が必要。
価格・目標・手順は Claude の提案であり、検証済みではない。

## 1. 一言でいうと

「業種」ではなく「どの会社にもある1つの業務」に絞り、AIエージェントを**固定メニュー・固定価格・2週間納品**で入れる。

業種を絞らない代わりに業務を絞る。毎回ゼロから作る受託にすると、1人では回らないため。

## 2. 売るもの（メニューは3つだけ）

| メニュー | 何をするか | 向いている客 |
|---|---|---|
| A. 問い合わせ返信の下書き | メール・LINE・フォームの問い合わせに、過去の返信と社内資料をもとに返信案を作る。人が確認して送る | 問い合わせが日に10件以上ある会社・店舗 |
| B. 見積書・提案書の下書き | ヒアリングメモや録音から、自社の書式で見積書・提案書の案を作る | 工務店、制作会社、士業、卸など |
| C. 口コミ・予約まわりの対応 | Googleマップの口コミへの返信案、予約の問い合わせへの一次応答 | 飲食、美容、クリニック、宿泊 |

- 最初に売るのは **A だけ**。業種を問わず存在し、効果（返信にかかる時間）が測りやすい。
- どれも「下書きまで」とし、**送信は必ず人が押す**。誤回答の事故を防ぎ、導入の心理的な壁も下がる。

## 3. 価格（提案）

| 項目 | 価格 | 備考 |
|---|---|---|
| 業務診断（30分、オンライン） | 無料 | 営業を兼ねる |
| 導入（初期設定、2週間） | 15〜30万円 | 最初の3社は5万円か無料で事例を作る |
| 月額（保守・改善・API利用料込み） | 2〜5万円 | 1社あたり月2時間以内の作業に収める |

- 参考相場：エージェント受託はPoC 100〜500万円、月額保守10〜100万円（研修会社の自社記事ベース）。これより一桁安い「小さく始める枠」を狙う。
- 補助金：デジタル化・AI導入補助金2026（通常枠で最大450万円、補助率1/2〜2/3）、小規模事業者持続化補助金（上限50万円）は客側が使う制度。支援事業者としての登録要件は未確認なので、最初は補助金なしでも払える価格にしておく。

## 4. 目標の数字（提案）

- 6か月後：月額契約10社 × 平均3万円 ＝ 月30万円 ＋ 導入費
- 12か月後：月額契約25社 ＝ 月75万円前後
- 1人で見られる上限は30〜40社程度と見込む。超えたらメニューをツール化するか、人を入れる。

## 5. 客の見つけ方（知人なしで始める前提）

中国の実例では、失敗の最大要因は集客だった。客先がない分、ここに一番時間を使う。

1. **既に中小企業を客に持つ人と組む**（最優先）
   - 税理士、社労士、Web制作会社、ITコーディネータ、商工会議所の経営指導員。
   - 紹介料（導入費の20〜30%）を払う形にする。1人の紹介者から複数社につながる。
2. **こちらから直接声をかける**
   - Googleマップで「口コミに返信していない」「問い合わせ先がフォームのみ」の店舗・会社を探し、その会社向けの返信案を実際に作って送る。
   - 1日10件、4週間で200件を目安にする。
3. **スキル販売サイトに出す**
   - ココナラ、ランサーズ、クラウドワークスに固定メニューを出品。単価は低いが最初の実績と評価が取れる。
4. **事例を発信する**
   - 1社目から「導入前後で返信時間が何分から何分になったか」を note と X に書く。2以降の返信率が上がる。
5. **無料セミナー**
   - 商工会議所や自治体の創業支援施設で「問い合わせ対応をAIで半分にする」30分講座。3社目の事例ができてから。

## 6. 作り方

- 構成：Claude API ＋ ワークフロー（n8n か Dify）＋ 客が既に使っている道具（Gmail、LINE公式アカウント、Googleスプレッドシート、kintone など）。
- 客に新しい画面を覚えさせない。返信案はいつものメールの下書きやLINEの管理画面に届く形にする。
- 1社目で作ったものをテンプレート化し、2社目以降は設定の差し替えだけで済むようにする。
- 自前の開発が必要な部分は Claude Code で作る。

## 7. 90日の進め方

| 期間 | やること | 次へ進む条件 |
|---|---|---|
| 1〜2週 | メニューAの見本を自分のメールで作る。1枚の説明資料と申込みフォームを作る。本業の就業規則（副業可否）を確認 | 見本が動く |
| 3〜6週 | 紹介者候補10人に連絡、直接の声かけ200件、ココナラ出品。無料〜5万円で3社に導入 | 3社が実際に毎日使っている |
| 7〜10週 | 3社の数字を事例にして発信。正規価格で販売開始。テンプレート化 | 正規価格で2社が契約 |
| 11〜13週 | 月額契約5社を目指す。メニューBかCを追加するか判断 | 月額5社、解約ゼロ |

**やめる・変える基準**：200件に声をかけて診断の申込みが5件未満なら、メニューか対象を変える。3社に入れても毎日使われないなら、業務の選び方が違う。

## 8. リスクと対策

| リスク | 対策 |
|---|---|
| 誤回答で客に迷惑がかかる | 自動送信しない。下書きのみ。契約書に免責を入れる |
| 個人情報の取り扱い | 委託契約と秘密保持契約を結ぶ。学習に使われない設定のAPIを使う。医療・要配慮情報は当面扱わない |
| 保守で時間が溶ける | 月額に含む作業時間の上限を決める。客ごとの個別改造をしない |
| 大手や無料ツールが同じ機能を出す | 価値を「ツール」ではなく「その会社の資料に合わせた設定と改善」に置く |
| 競合が多い | 固定価格・2週間納品・1業務だけ、を前面に出す |
| 本業との兼ね合い | 就業規則の確認、開業届、インボイス登録の要否を先に確認 |

## 9. まだ確認できていないこと

- 個人講師・個人の導入支援の実勢単価
- 補助金の支援事業者登録の要件（個人事業主で登録できるか）
- 紹介料の相場
- 日本で同じ形（固定メニュー・低価格）を個人でやっている人の収益実績
